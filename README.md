## ✨ Overview

**Pritam OS** reimagines the traditional developer portfolio as an interactive desktop environment inspired by Windows 11.

Instead of navigating through conventional portfolio pages, visitors can explore different sections through desktop shortcuts, application windows, a Start menu, and a built-in terminal.

The interface combines modern frontend technologies with a clean visual design, responsive layouts, and intuitive interactions.

## 🚀 Key Features

| Feature | Description |
|---|---|
| 🖥️ Interactive Desktop | Windows-inspired desktop environment |
| 📌 Start Menu | Application launcher with search functionality |
| 🪟 Window Manager | Open, minimize, maximize, drag, and close windows |
| 👨‍💻 Developer Profile | Personal information and professional background |
| 💼 Projects | Explore projects with search and category filters |
| ⚡ Skills & Experience | Dedicated sections for technical skills and experience |
| 🎓 Education & Certificates | Academic background and certifications |
| ⌨️ Interactive Terminal | Command-based portfolio exploration |
| 📄 Resume Viewer | Preview and download my resume |
| 🎨 Theme Support | Light and dark appearance |
| 📱 Responsive Interface | Adaptable desktop, tablet, and mobile layouts |

## ⚙️ Getting Started

Want to explore the project locally?

### Prerequisites

- Node.js 20+
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project**

```bash
cd YOUR_PROJECT_FOLDER
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Build for production**

```bash
npm run build
```
