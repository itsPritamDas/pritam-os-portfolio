# Pritam OS — Interactive Developer Portfolio

**A Windows 11-inspired interactive portfolio that transforms a traditional developer portfolio into a desktop-like experience.**

Pritam OS is a personal portfolio built to showcase my technical skills, projects, experience, and achievements through an interactive desktop environment inspired by Windows 11.

Designed with a focus on usability, clean visuals, responsive layouts, and smooth interactions, it offers a unique way to explore my developer profile.

## ✨ Key Highlights

- **Interactive Desktop:** Windows-inspired interface with desktop shortcuts and taskbar.
- **Application Experience:** Explore profile information, projects, skills, experience, education, and certifications.
- **Window Management:** Interactive application windows with familiar desktop controls.
- **Built-in Terminal:** A command-based interface for exploring portfolio information.
- **Resume Access:** Integrated resume preview and download.
- **Responsive Design:** Optimized experience across desktop, tablet, and mobile devices.
- **Modern UI:** Clean typography, subtle animations, and light/dark themes.

## 🛠️ Technology Stack

## 🚀 Getting Started

To run the project locally:

```bash
git clone YOUR_REPOSITORY_URL
cd YOUR_PROJECT_FOLDER
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```
